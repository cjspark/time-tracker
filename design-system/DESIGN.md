# Eutide — Design System

> EU 系列 · 时间管理 app（原 Annuli）
> `eu-` = 希腊语"好/美好"（eudaimonia 丰盈人生）；eu + tide 潮汐 = 生命的自然节律
> 本文件是设计体系的**精炼规范**；完整设计文档见 [`../design-docs/eutide-design.md`](../design-docs/eutide-design.md)

---

## 一、身份

Eutide 是一个**温柔的自我目击者**。用户带着一点焦虑打开它想知道"我最近还好吗"，它诚实回答，但用让人放松、而非更焦虑的方式。不是 KPI 仪表盘，不是打卡机，不是效率优化工具——更像一个懂你的朋友，陪你翻翻最近的日子。

## 二、五条设计原则

1. **鼓励优先** — 以"你做了什么"为主视角，不是"你没做什么"。完成态显眼，缺口静默。
2. **无压记录** — 忘记记录不是失败。无 streak、无"已断签"、无愧疚提示。空白静默。
3. **随意浏览** — 信息密度低，主内容一眼可见，深挖是可选项。像翻杂志，不像看报表。
4. **正反馈驱动** — 用户因"看到自己"而回来，不是因"怕断掉"而回来。
5. **安全容纳** — 负面情绪不被惩罚。低落是数据，不是失败。低落/压力不用警告色。

## 三、语气（Voice & Tone）

像有洞察力的朋友，不是系统通知。第二人称"你"；句子短、动词优先；不说教、不催促。

| 场景 | ❌ | ✅ |
|---|---|---|
| 空状态 | 暂无数据 | 这周还很安静，先从今天开始 |
| 记录成功 | 保存成功 | 记好了 |
| 目标完成 | 任务已完成 | 做到了 |

**emoji 边界**：emoji 只在**记录打情绪标签**时出现；**复盘报告里全程不出现**（报告是严肃的回看时刻）。

## 四、视觉基调

- 莫兰迪低饱和大地色系，仅浅色模式。全局饱和度 25–42%，"每个色像蒙了一层灰"。
- 暖米背景、橄榄绿强调、陶土红代替刺眼正红。
- 圆角 16/12px，大量留白，软阴影，spring 动效（禁线性）。
- 所有色值 / 圆角 / 字体一律引用 [`tokens.css`](./tokens.css)，不写死。

## 五、明确反模式（禁止引入）

Streak 连续计数 · 进度百分比 · 红色警告未记录 · 密集仪表盘 · 强推送提醒 · 过度炫技动效 · 全局深色模式。

## 六、签名机制

- **MoodBlend 色彩引擎**：情绪时间分布 → 一个颜色。在 **OKLab** 感知空间混合（避免"泥色"），`权重^dominance` 归一化后加权平均，再乘 chroma 放大彩度。定稿参数：**chroma 3.2 / dominance 3.5**。复盘水晶球、日历时间块、生命树果实共用。参考实现 `../design-docs/liquid-lab.html`。
- **情绪水晶球**（复盘远景）：四颗等大玻璃球（生产/日常/创造/娱乐），满球 = 24h，水位 = 用时，水色 = 主导情绪。参考 `../design-docs/crystal-ball-v4.html`。
- **玻璃 + 液体质感**：深度饱和渐变 + 波动水面 + 高光 + 色散。iOS 26+ 用原生 `.glassEffect()`。参考 `../design-docs/glass-lab.html`。

## 七、四类效率（按驱动力定义，不按活动名字）

| 类别 | 驱动力 | token |
|---|---|---|
| 生产 | 为了完成（工作、任务、交付） | `--eu-eff-productive` |
| 创造 | 为了成长（创作、搭建、学本领） | `--eu-eff-creative` |
| 娱乐 | 为了放松（玩、看剧、消遣） | `--eu-eff-enjoyable` |
| 日常 | 为了生活（吃饭、通勤、家务） | `--eu-eff-daily` |

一个活动最多打 2 个效率标签，各算 100%。

## 八、情绪五档

😊愉悦 / 😌平静 / 😐还行 / 😔低落 / 😤压力（token `--eu-mood-*`）。
